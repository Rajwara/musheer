# Product photos

Upload 3 photos per product: **front**, **side** and **back**. Name each file `<product>-<view>`, for example `stand-collar-thobe-white-front.webp`.

- Formats: `.webp`, `.jpg`, `.png` (WebP is smallest).
- Shape: portrait **4:5**, about **1200 x 1500 px**. Keep the garment centred with some space around it.
- A photo replaces the drawing with the same name; you don't need to delete anything. The site picks photos up when it is rebuilt.
- Upload in batches (GitHub takes up to 100 files at a time).
- Missing a view? Upload just the front and the drawing stays for the others.
